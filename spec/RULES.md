# Event Rules — Lahore Smog Intelligence Challenge

## Allowed
- Coding/chat assistants, IDE agents (Copilot, Antigravity, etc.)
- Hosted or local LLMs, any open-source libraries and frameworks
- Google Colab, GitHub, any notebook environment
- Only **free-tier hosted models/APIs or free local models**. No paid API usage — this keeps the event cost-free and fair across teams.

## Not allowed
- Seeking or guessing hidden holdout labels
- Accessing another team's work or repository
- Bypassing the 3-attempt submission limit
- Exploiting data leaks instead of genuinely forecasting
- Fabricating citations or forecast numbers
- Submitting code your team cannot run or explain
- Committing API keys or secrets to the repository

## Team composition
- Teams of up to 4, or solo
- Suggested roles: Data lead, Forecast lead, RAG/safety lead, Integrator/captain

## Submission
- **One final submission only**, made after the 4-hour build window ends.
- Everything is submitted together at the deadline: `predictions.csv`, your GitHub repository, your 25 answers, your AI error log, and your recommendation.
- There is no separate early checkpoint and no second attempt — validate your files locally before the deadline.
- Submitting after the deadline is not accepted; evaluation begins once the window closes.

## Fallback
- If behind schedule, submit a leak-free recent-average baseline for your forecast rather than nothing.
- A reference forecast is released at the event's midpoint for use in the RAG assistant only if needed — disclose its use in your recommendation document.
