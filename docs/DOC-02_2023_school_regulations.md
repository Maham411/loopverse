# Smog School Closure Policy — Version 1 (SUPERSEDED)

This policy has been replaced by DOC-03 and should not be used for current decisions.

Under this version:
- Schools close only when PM2.5 exceeds 300 µg/m³ for two consecutive days.
- Outdoor sports periods are suspended above 200 µg/m³.
- No provision existed for partial/half-day closures.
